# ╚═══════════════════════╝
Proyecto elaborado en C++ encargado de simular un sistema de manejo de archivos similar a la consola de Windows, esto, mediante el uso de árboles binarios para la gestión de carpetas y archivos.

**PROCESO DE INSTALACIÓN Y EJECUCIÓN:**
1. Descargar el archivo "CMD_AB.exe" desde el repositorio "MOAR_Estructura_Datos" en el branch "MINIPROYECTOS", dentro de la carpeta "PROYECTO 6 - BST".
2. Mover el archivo descargado a una carpeta de preferencia.
3. Ejecutar el programa "CMD_AB.exe".

**Uso del programa:**
Al ejecutar e iniciar el programa, se advierte que no existe un archivo .json inicial, por lo que se generará uno nuevo y propio. Después, para continuar hay que pulsar la tecla ENTER.
Dentro del programa, se puede ver una lista de comandos para utilizar en la consola tipo CMD.

**Funciones:**
- Gestión de carpetas (directorios) y archivos.
- Preorden visible de la estructura de los directorios.
- Papelera disponible para la eliminación y restauración de archivos.
- Guardado y cargado tanto para el árbol de directorios como para el de la papelera.
- Función de búsqueda con la cual se pueden buscar distintos directorios (posee "autocompletado").
