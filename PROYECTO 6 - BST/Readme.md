# ╚═══════════════════════╝
Proyecto elaborado en C++ encargado de simular un sistema de manejo de archivos similar a la consola de Windows, esto, mediante el uso de árboles binarios para la gestión de carpetas y archivos.

*Proceso de instalación y ejecución:*
1. Descargar el archivo "CMD_AB.exe" desde el repositorio "MOAR_Estructura_Datos" en el branch "MINIPROYECTOS", dentro de la carpeta "PROYECTO 6 - BST".
2. Mover el archivo descargado a una carpeta de preferencia.
3. Ejecutar el programa "CMD_AB.exe"
